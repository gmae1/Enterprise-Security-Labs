# Phase 1 Networking

###  Phase 1 focuses on building practical networking and packet-analysis skills using Wireshark, pfSense, and the SEC-LAB environment. Labs explore protocols such as ARP, ICMP, DNS, TCP, UDP, HTTP/HTTPS, and SSH while analyzing how devices communicate across Layer 2 and Layer 3. Each lab connects networking fundamentals with real-world troubleshooting and cybersecurity analysis.
